# Gestore File CP

Gestore file veloce e moderno per Windows, scritto in Rust. Pensato come alternativa leggera a Esplora file.

## Caratteristiche

- **Veloce e leggero**: le cartelle si leggono in background, quindi la finestra non si blocca, e anche con migliaia di file si disegnano solo le righe visibili.
- **Ordine sensato**: di base i file sono ordinati per data di download/salvataggio, dai più recenti. Si può ordinare anche per nome, data di modifica, dimensione e tipo.
- **Schede**: più cartelle aperte insieme (Ctrl+T per aprirne una, Ctrl+W per chiuderla).
- **Anteprima a destra**: immagini, file di testo e informazioni sulle cartelle.
- **Stile Material colorato**, con tema chiaro e scuro.
- **Impostazioni**: tema, cartella iniziale, ordinamento predefinito, file nascosti, conferma del cestino.
- Rinomina, nuova cartella, cestino, copia del percorso e menu col tasto destro.

## Scorciatoie

| Tasto | Azione |
|---|---|
| Ctrl+T / Ctrl+W | Nuova scheda / chiudi scheda |
| Ctrl+Tab | Scheda successiva |
| F5 | Aggiorna |
| F2 | Rinomina |
| Canc | Sposta nel cestino |
| Invio | Apri |
| Backspace | Cartella superiore |
| Alt+← / Alt+→ | Indietro / Avanti |

## Installazione

Scarica `Installa Gestore File CP 1.0.exe` dalla sezione **Releases** (o dagli artefatti di **Actions**) e avvialo. In alternativa puoi usare `Gestore File CP.exe` direttamente, senza installare nulla.

## Compilare dai sorgenti

1. Installa Rust da https://rustup.rs
2. (Facoltativo, per l'installer) installa Inno Setup da https://jrsoftware.org/isdl.php
3. Esegui `compila.bat`: i file escono nella cartella `dist`.

Su GitHub la compilazione parte da sola a ogni caricamento (scheda **Actions**).
